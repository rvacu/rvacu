## A few things I've built

### [Endfield for CrossOver](https://github.com/rvacu/Endfield-CrossOver-Patcher)
A native SwiftUI macOS app that turns a complicated CrossOver compatibility setup into a safer one-click workflow. It includes runtime validation, backups, repair logic, testing, and CI.

### [Reliable Transport over UDP](https://github.com/rvacu/reliable-udp-transport)
A Python transport layer built over UDP with sequence numbers, CRC32 checks, sliding windows, cumulative ACKs, and retransmission.

### [Distributed Distance-Vector Routing Simulator](https://github.com/rvacu/distributed-routing-simulator)
A five-router simulator where concurrent routers exchange routing updates over TCP and recalculate paths until the network converges.

### [Campus Bike Rental Database](https://github.com/rvacu/campus-bike-rental-database)
A Java and Oracle SQL project focused on relational data, queries, constraints, prepared statements, and transaction behavior.
